# Calculator

A responsive and user-friendly calculator built using HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal number support
- Delete and clear functions
- Calculation history
- Local storage for saving history
- Responsive design for mobile and desktop
- Light/Dark theme support
- Keyboard input support

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run / Setup

1. Download or clone this repository.
2. Open the Calculator project folder.
3. Open the `index.html` file in your web browser.
4. The calculator is ready to use.
